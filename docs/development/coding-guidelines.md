# Coding Guidelines — Plateforme de Chat

## Conventions (à adapter à la stack retenue)

- Nommage camelCase côté JS, PascalCase composants, kebab-case fichiers.
- Structure frontend/backend séparée.
- Typage/validation des entrées (Joi/Zod — à valider).
- Gestion des erreurs centralisée.
- Tests unitaires/intégration.
- Formatage/linting (ESLint/Prettier).

## Dépendances

Ne pas introduire de dépendance sans justification.
